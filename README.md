# Taama Claim Checker

A deterministic claim compliance checker for the Australia market, built for the Taama Developer Take-Home Assignment.

## Current Scope

- Python
- FastAPI
- Docker
- Docker Compose
- Pytest
- CLI-first architecture
- Deterministic compliance evaluation

## Goal

Given a product claim, evaluate its compliance against the provided Australian regulatory source bank and return:

- Green / Amber / Red verdict
- Matching regulatory rule
- Traceable source reference
- Plain-English explanation
